# Участие в разработке Holarchy Orchestrator

Мы приветствуем вклад в развитие проекта! Пожалуйста, следуйте данным рекомендациям:

## Настройка окружения

1. Клонируйте репозиторий и перейдите в корень проекта.
2. Установите пакет в режиме редактирования со всеми зависимостями:
   ```bash
   pip install -e .[all,test]
   ```

## Контроль качества и тестирование

Перед отправкой изменений убедитесь, что код проходит все проверки:

```bash
# Линтинг и форматирование
ruff check .
ruff format .

# Проверка типизации
mypy src/holarchy

# Запуск тестов оркестратора
pytest tests/
```

## Стандарты разработки

- Все изменения должны проверяться через **Ruff**.
- Все новые функции и методы должны содержать аннотации типов и проходить проверки **Mypy**.
- Следуйте существующему стилю декларативных графов и обработчиков конечных автоматов.
- Сохраняйте лицензионные заголовки MPL-2.0 во всех исходных файлах.
