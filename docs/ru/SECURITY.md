# Политика безопасности

Если вы обнаружили потенциальную уязвимость в этом пакете, пожалуйста, не открывайте публичное Issue. Вместо этого отправьте письмо на адрес [madgagarin@gmail.com].

## Модель безопасности

Этот пакет соответствует модели безопасности **HLN (Holarchical Logic Network)**, основанной на принципах Zero Trust:

- **Архитектура Zero Trust**: взаимная проверка подлинности и криптографическая подпись каждого пакета данных.
- **Mutual TLS (mTLS)** для защищенного сетевого взаимодействия между узлами.
- **Краткосрочные токены доступа (STS)** с динамической ротацией.
- **Отсутствие входящих портов у исполнителей (PULL-модель)**: воркеры подключаются к оркестратору самостоятельно.
- **Envelope Encryption**: конвертное шифрование токенов клиентов и воркеров в хранилище Redis.
- **Криптографическая защита от повторов (Replay Protection)** на основе одноразовых nonce и временных меток.

Подробное описание принципов безопасности приведено в [Спецификации безопасности HLN](https://github.com/madgagarin/hln/blob/main/SECURITY.md).
